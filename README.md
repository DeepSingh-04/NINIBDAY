# A Special Birthday Wish for NINI
[![Ask DeepWiki](https://devin.ai/assets/askdeepwiki.png)](https://deepwiki.com/DeepSingh-04/NINIBDAY)

This repository contains a personalized and interactive single-page web application created as a 19th birthday gift for NINI. Built with vanilla HTML, CSS, and JavaScript, it offers a magical, multi-screen journey filled with animations, heartfelt messages, and interactive elements.

## ✨ Features

*   **Interactive Storytelling:** A step-by-step experience that guides the user through multiple screens with personalized birthday messages.
*   **Animated Particle Background:** A dynamic particle canvas that subtly reacts to mouse movements, creating an immersive atmosphere.
*   **Custom Cursor:** A unique cursor with a trailing effect enhances the magical theme of the site.
*   **Virtual Birthday Cake:** An animated cake featuring 19 candles that can be "blown out" by the user.
*   **Smooth Screen Transitions:** Custom balloon-burst animations provide a delightful transition between different sections of the page.
*   **Background Music:** An embedded YouTube audio track plays in the background to set the mood, complete with a mute/unmute control.
*   **A Special Gift:** Includes a download button for a personalized birthday poem.

## 💻 Tech Stack

*   **HTML5:** Structures the content of the webpage.
*   **CSS3:** Handles all styling, animations (including keyframes for candles and transitions), custom properties (variables), and layout.
*   **JavaScript (Vanilla):** Powers all the interactivity, including:
    *   The particle system on the HTML Canvas.
    *   Screen management and transitions.
    *   The custom cursor and its trail effect.
    *   Interaction logic for blowing out the cake's candles.
    *   Integration and control of the YouTube IFrame Player API for background music.

## 🚀 How to Experience It

To view and interact with the birthday page, simply follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/deepsingh-04/NINIBDAY.git
    ```
2.  **Navigate to the directory:**
    ```bash
    cd NINIBDAY
    ```
3.  **Open the file:**
    Open the `README.HTML` file in any modern web browser (e.g., Google Chrome, Firefox, Safari).

That's it! The celebration will begin automatically.
